한지훈의 iPhone — iOS 26 kit 준비 버전

index.html을 실행합니다. 사진/콘텐츠/잠금 해제/카카오톡 알림은 기존 v5 그대로입니다.

추가된 부분:
- 제공한 iOS 26 키트의 호스팅 CSS 연결 (CSS 자체를 복사하거나 분석하지 않음)
- 휴대폰 컨테이너에 ios-surface 추가
- PC 기준 화면 너비를 402px로 변경, 모바일에서는 전체 폭

주의: 개별 kit 컴포넌트의 문서 주소가 검색/접속 도구에서 모두 실패했습니다.
지침에 따라 구성요소의 클래스명과 속성을 추측하여 새로 만들지 않았습니다.
따라서 내부 UI는 아직 키트 컴포넌트로 교체되지 않았습니다.
문서 예시를 받은 뒤 navigation bar, list, segmented control, tab bar, notification, status bar, home indicator, widgets 순으로 교체할 수 있습니다.
키트 CSS는 외부 URL로 연결되므로 인터넷 연결이 필요합니다.
